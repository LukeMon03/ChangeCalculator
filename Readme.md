# Change Calculator App!
A C# .NET console application that calculates change amount for a given transaction. 

## Currencies Supported
	- British Pound

### Adding addtional Currencies
If  you are interested in expanding the currency base, then add another dictionary to the Currencies folder and input the denominations of that currency. **Currently the calculator has been hard coded to handle Sterling only** 

## Running the application
Open solution in visual studio, make sure ChangeCalculatorApp is set as start up project. Then hit run. You will then be prompted to input the Price of the item, and then the amount being paid by the consumer.
